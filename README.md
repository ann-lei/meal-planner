# meal-planner

A web app to save recipes, plan meals for the week, and list out grocery list

## Database design

### recipes
- name
- link (which would be optional)
- time
- servings
- steps
- user

### recipe ingredients
- amount
- unit
- ingredient name
- category (Produce, Dairy, etc...)

### meals
- date
- meal type
- recipe
- user

## Ideas

- A pantry of what is already in my kitchen
